# PC Guy

[English](README.md) | 中文

> 由 [samai.cc](https://samai.cc) 集团出品的 Windows 系统优化工具箱。

PC Guy 是一款用 Go 编写的 Windows 桌面工具，内置基于 Web 的管理面板和系统托盘图标，帮助你轻松优化和维护 Windows 电脑。

## 功能特性

- **内存清理**：扫描内存占用，一键通过清空进程工作集释放内存。
- **CPU 监控**：查看 CPU 占用、核心数、温度（部分设备可能不支持温度）及进程数。
- **进程管理**：列出所有进程及其 CPU/内存占用，按占用排序，并终止可疑或高占用进程（自动刷新）。
- **垃圾清理**：扫描并清理系统临时文件、回收站、浏览器缓存、Windows 日志、预读取文件和最近文档。
- **软件管理**：列出已安装软件，一键卸载。
- **启动项管理**：查看 / 启用 / 禁用 / 删除启动项（注册表 Run 键与启动文件夹）。
- **强制删除**：递归强制删除文件夹（忽略只读 / 隐藏属性）。
- **智能体接管**：内置 `samcommand` 服务。临时开启“接管模式”，让另一个 AI 智能体通过公开 URL 远程执行命令以协助排障；面板会显示公开地址与鉴权 token —— 用完后关闭即可。
- **系统托盘**：右键菜单包含互斥的“开机启动 / 取消开机启动”、“开启/关闭接管模式”、“管理面板”和“退出”。

## 下载与安装

前往 [Releases](https://github.com/samaidev/pcguy_r/releases) 页面，下载最新的 `PCGuy-setup-x.x.x.exe` 安装包，双击安装即可；桌面和开始菜单都会创建快捷方式。

便携版（`PCGuy-x.x.x-portable.zip`，免安装）随每个 Release 附带，并镜像保存在本仓库中。

**最新版本：v1.1.14** — 内置 `samcommand` v1.9.0：

- 智能体接管模式的文件传输现在支持 **最大 1GB 的文件**，采用 **分片断点续传** —— 传输中断后自动从服务端确认的字节位续传，不再从 0 重传。
- Web 终端前置英文提示：上传仅支持 1GB 以内（分片断点续传）；超限文件在任何字节发出前即被拒绝，避免白上传。
- 针对 aitun 隧道的稳定性优化：自适应分片大小、指数退避 + 抖动重试、逐分片完整性校验。

## 使用

启动后，PC Guy 图标出现在系统托盘。右键可打开管理面板或退出。

界面默认英文，同时支持中文。可通过面板右上角按钮或启动参数切换：

```bash
pcguy.exe            # 英文（默认）
pcguy.exe --lang zh # 中文
```
